# 🤝 Fonctionnement de l'équipe

## Pour ajouter une séance

Créer un fichier dans `CARNET-DE-BORD/` à partir de `MODELE-SEANCE.md`.

## Pour une modification technique

Documenter :
- ce qui a changé ;
- pourquoi ;
- les conséquences ;
- les essais réalisés.

## Règle importante

Le dépôt est un carnet de bord : les informations doivent correspondre au travail réellement effectué par l'équipe.
