# 🖥️ Interface Course en Cours

## Première visite

L'utilisateur pourra choisir son équipe : Conception, Modélisation 3D, Matériaux, Fabrication, Assemblage, Essais ou Présentation.

Le choix personnalise l'affichage. Il ne remplace pas les permissions GitHub : l'accès réel aux fichiers reste contrôlé par GitHub.

## Objectif

Créer un tableau de bord interactif avec progression, équipes, annotations, problèmes, idées et dernières séances.

## Laboratoire technique

La page `laboratoire.html` permet aux élèves de déposer des fichiers localement, d’afficher les modèles STL, OBJ, GLB/GLTF et 3MF, de lire du code et des documents, et d’interroger l’assistant IA sur le contexte technique disponible. Les fichiers ne sont pas téléversés automatiquement. Les formats CAO natifs (SOLIDWORKS, STEP, IGES) sont identifiés mais nécessitent une exportation pour la visualisation directe.
