# 🖥️ Interface Course en Cours

## Première visite

L'utilisateur pourra choisir son équipe : Conception, Modélisation 3D, Matériaux, Fabrication, Assemblage, Essais ou Présentation.

Le choix personnalise l'affichage. Il ne remplace pas les permissions GitHub : l'accès réel aux fichiers reste contrôlé par GitHub.

## Objectif

Créer un tableau de bord interactif avec progression, équipes, annotations, problèmes, idées et dernières séances.
