3. Comprendre et progresser

Pose une question sur le fichier sélectionné. L’assistant reçoit le nom, le format et les informations techniques disponibles ; le code texte peut être ajouté à la question.

💡 Astuce élève

Demande à l’IA d’expliquer avant de corriger. Vérifie toujours les cotes, le code et les résultats avec ton équipe ou ton professeur.

Formats pris en charge

🧊 3D affichable

STL, OBJ, GLB, GLTF et 3MF. Rotation, zoom, mesures et export d’une capture PNG. Pour un GLTF avec fichiers externes, importe aussi les fichiers BIN/textures associés.

💻 Code

INO, C/C++, Python, JavaScript, JSON, HEX et fichiers texte : aperçu lisible et contexte pour l’IA.

🖼️ Plans et documents

Images, SVG et PDF : aperçu dans le navigateur.

🛠️ CAO native

STEP/STP, IGES/IGS et SOLIDWORKS SLDPRT/SLDASM/SLDDRW/SLDDRT sont reconnus, mais doivent être exportés en STL/STEP/GLB ou PDF pour un aperçu direct.

Les fichiers restent locaux jusqu’à ce que tu demandes explicitement une analyse IA. L’assistant ne peut pas reconstruire toutes les fonctions paramétriques SOLIDWORKS depuis le navigateur. Pour une pièce native, exporte une copie depuis SOLIDWORKS ou FreeCAD.
