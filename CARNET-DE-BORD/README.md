# 📓 Carnet de bord

Cette partie constitue le journal de travail de l'équipe.

## Règle de fonctionnement

Après chaque séance :

1. Copier `MODELE-SEANCE.md`.
2. Créer un fichier `SEANCE-XX.md`.
3. Compléter toutes les rubriques.
4. Ajouter les photos, plans ou fichiers utiles.
5. Enregistrer les décisions techniques importantes.
6. Indiquer clairement ce qui doit être fait à la prochaine séance.

## Contenu attendu

- Date et durée
- Membres présents
- Objectifs
- Travail réalisé
- Difficultés rencontrées
- Solutions
- Choix et décisions
- Résultats / preuves
- Travail à poursuivre

Les comptes rendus doivent rester factuels et permettre à un enseignant de suivre l'évolution du projet.
