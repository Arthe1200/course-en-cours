# 📅 Journal par journée

Toutes les informations d'une séance de travail sont regroupées dans le dossier correspondant à sa date.

## Organisation

`JOURNEES/YYYY-MM-DD/`

Exemple :

```
JOURNEES/
└── 2026-10-07/
    ├── README.md
    ├── photos/
    ├── fichiers/
    └── comptes-rendus/
```

## Créer une journée

Le moyen recommandé est d'ouvrir une **Issue → Nouvelle séance**. L'automatisation crée automatiquement le dossier de la journée.

Une journée peut ensuite contenir :
- le compte-rendu ;
- les photos ;
- les fichiers de conception ;
- les modèles 3D ;
- les documents utiles ;
- les décisions prises ;
- les résultats des essais.

> Une même journée peut concerner plusieurs points du suivi. L'automatisation reporte ces points dans leur historique.
